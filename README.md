# C Bullet Hell

A small 2D bullet-hell game built in C using raylib.

## About

My first C game-development project, completed by following a tutorial. The aim was to learn the basics of game programming, including game loops, player controls, collision detection, enemy spawning and game states.

## Technologies

- C
- raylib
- CMake
- Visual Studio

## Controls

- WASD - Move
- Left mouse button - Shoot
- Enter - Start/restart

## Build

This project uses CMake and raylib. See `CMakeLists.txt` for build configuration.
